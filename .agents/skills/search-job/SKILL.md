# Search job

Purpose of the skill: Find the best job opportunities based on [my CV](../../../dist/Francesco-Vicidomini-CV.pdf).

## Where to search

For the search don't use only LinkedIn, but also other job boards like Indeed, Glassdoor, Joiner, MichaelPage ecc...  
To improve your search use the information red in [Where to search](references/WHERE-TO-SEARCH.md).

## What to search

To know what kind of job you have to have the use the information retrieved in [What to search](references/WHAT-TO-SEARCH.md).

## Report of the results

After the search, create a report with the following information for each job opportunity:

- Job title
- Company name
- Location
- Salary range
- Job description
- Application deadline
- Link for the application page
- A score from 0 to 10 based on how well the job opportunity matches my skills and preferences.
