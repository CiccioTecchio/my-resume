# Changelog

## 1.0.0

- Replaced the previous LaTeX resume with a version built using HTML5, CSS, and JavaScript.
- Organized the resume content into easily editable JSON files.
- Optimized the layout for viewing and printing as a two-page A4 PDF.
- Added automated tagged PDF generation using Chromium and Puppeteer.
- Added PDF post-processing for metadata, XMP, document identifiers, language, link accessibility, and final format validation.
